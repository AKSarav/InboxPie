🛡️

Privacy isn't a setting. It's the architecture.

InboxPie never collects, stores, or transmits your email to any InboxPie server — because there are no InboxPie servers. The semantic index is built and queried on your own machine. When you opt into cloud AI, data flows device → your own API account, exactly as if you'd pasted it yourself. You can see every step in the live “Thinking” panel.
